# Foreign K-Startup — Startup Procedures Guide

A React-based web application providing a guide to startup procedures in South Korea for foreign entrepreneurs.

---

## Prerequisites

Make sure you have the following installed on your machine:

- [Node.js](https://nodejs.org/) (v16 or higher recommended)
- [npm](https://www.npmjs.com/)

---

## Installation

**1. Clone the repository**

```bash
git clone https://gitlab.com/AdemBslm_2/foreign-k-startup.git
```

**2. Navigate into the project directory**

```bash
cd foreign-k-startup
```

**3. Install dependencies**

```bash
npm install
```

---

## Running the App

```bash
npm run start
```

The app will be available at **http://localhost:3000** in your browser.

---

## Linting (CI)

To check the code quality and detect any linting errors:

```bash
npm run lint
```
